# Hellow

## Cara Menjalankan

Ikuti langkah-langkah berikut untuk menjalankan halaman HTML ini:

1. Clone atau download repository ini.
    - Jika menggunakan git:
      ```bash
      git clone https://github.com/username/hello-world-html.git
      cd hello-world-html
      ```

2. Buka file `hello.html` menggunakan browser.
    - Klik dua kali pada file `hello.html`, atau
    - Klik kanan → "Open with" → Pilih browser favoritmu (Chrome, Firefox, dll).

3. Lihat hasilnya!
    - Teks **Hello World** akan muncul di halaman web.

## Catatan

- Tidak perlu web server atau alat tambahan.
- Bisa dijalankan secara offline.
- Cocok untuk latihan dasar HTML.
